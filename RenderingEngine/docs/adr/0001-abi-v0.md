# ADR 0001: Freeze the canonical CPU/GPU ABI v0

- Status: Accepted
- Date: 2026-08-23
- Contract: `abi-v0`

## Context

The compatibility renderer currently owns its scene and frame records inside a
small set of renderer/shader files. The planned CPU reference, software GPU,
Vulkan Ray Query, asset, and validation lines need one canonical representation
before they can develop independently. Native matrices, `float3`, GLM types,
and backend-specific hit payloads would make C++/HLSL layout and parity depend
on compiler or backend details.

Wave 0 must freeze a useful foundation without guessing Wavefront, temporal,
ReSTIR, or RT-pipeline payload structures.

## Decision

Adopt the records and descriptor registry specified by
`docs/contracts/abi-v0.md`.

Key decisions are:

- use explicit 16-byte float/uint lanes for every GPU-visible record;
- represent matrices as four explicit mathematical rows and evaluate `M * v`
  with four dot products on both CPU and HLSL;
- keep canonical scene data independent of every traversal backend;
- keep `GpuRayV0` traversal-only and defer path/RNG/queue state to ABI v1;
- freeze BSDF/LightSample mathematical responsibilities while deferring their
  concrete C++/HLSL records and offsets to ABI v1;
- reserve descriptor-set ownership now, while leaving sets 3-5 empty;
- keep the current analytic sphere/plane ABI as a temporary legacy contract,
  not part of the canonical triangle ABI;
- validate C++ layout at compile time and publish an HLSL/SPIR-V layout probe
  plus a machine-readable golden offset file.

The human name is `abi-v0`; numeric ABI value `1` is used so zero-filled,
uninitialized data cannot masquerade as a valid version.

## Alternatives considered

### Native C++ and HLSL matrices/vectors

Rejected because matrix-major rules, `float3` padding, GLM configuration, and
DXC layout options can silently disagree.

### One compact production layout immediately

Rejected for Wave 0. Packed normals, half precision, compressed vertices, and
bindless/backend-specific representations are valuable optimizations, but they
obscure the first correctness contract. Backends may later introduce private
optimized buffers while preserving conversion and parity against canonical v0.

### Put integrator state in the ray record

Rejected because it couples traversal to Megakernel/Wavefront execution and
would prematurely freeze ABI v1 queue semantics.

### Freeze acceleration-structure and SBT bindings now

Rejected because Wave 0 neither builds nor validates those paths. Only set
ownership is reserved.

## Consequences

- CPU and HLSL code can reject layout drift at build time.
- CPU, software GPU, and hardware traversal can compare stable IDs and hit
  semantics without sharing an implementation.
- The 64-byte canonical vertex and explicit instance matrices favor clarity
  over minimum bandwidth. A later private packed layout requires conversion
  tests rather than changing v0 in place.
- Previous rigid instance transform is present for the frozen scene contract,
  but motion/GBuffer/history records remain deferred to ABI v2.
- Reserved fields must remain zero; they are not an informal extension point.
- Any incompatible change requires a new ADR, ABI version, updated C++ and HLSL
  headers, updated static tests, and an updated offsets golden.
